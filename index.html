EclipseInformation.site

This website provides data of Solar Eclipses between the year 1900 to 2200. The data generated is by the author of this website, i230010, which does not guarantee is accurate. Solar Eclipse Dates and Besselian Elements data are generated by python on my github and Solar Eclipse Paths and Local Circumstances are generated by Javascript (from celestialprogramming).
